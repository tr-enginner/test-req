# SPI总线(软件↔内部单板)二级总线接口专属规则——检测到"SPI总线"板间通信/应答/轮询/遥测需求时注入

### SPI总线（软件↔内部单板）二级总线测试模型（强制）

**回读与触发分离（优先规则）**：涉及遥测验证时，首先通过一级 CAN 周期发送对应的“遥测帧轮询控制序列”，用于读取并验证遥测更新值和错误计数；覆盖本用例所有相关遥测帧，同一帧只声明一次循环，不同帧分别设置。默认第3.0秒开始、1秒周期，需求另有约定时以需求为准。该回读不是 SPI 轮询触发，软件自主轮询也不能省略回读。触发软件 SPI 轮询的步骤根据测试需要和需求依据另行添加；若软件自主轮询，按真实周期模拟单板返回，不虚构上游触发。不同节点的轮询顺序和间隔以需求为准，不能用一级回读周期替代。软件的轮询输出和监测结论放在预期结果，不得翻译成测试系统发送动作。

SPI 总线与二级CAN同属**二级总线**：被测软件经 SPI 与内部单板（下位机）通信——软件按 SPI 数据流定义组包，经 SPI 总线（初始 A 总线）向单板发送指令/轮询并等待返回；测试环境没有单板仿真组件，由**测试系统通过 SPI 总线主动发送应答/遥测数据模拟单板的被动返回**。测试视角铁律：**所有步骤都是测试系统主动发送**，**禁止以单板为参考视角编写步骤**。

步骤模式与二级CAN完全同构——**一级周期遥测回读 + 按需触发 + SPI 模拟应答/遥测交替**。以下触发步骤仅适用于需求给出了上游触发关系的场景，不能用它替代遥测回读：

1. **触发步骤（唯一一条，循环触发）**：通过**一级总线**（按需求指定，如 CANA）**以1秒为周期循环发送**上游数据流定义的一级指令。循环时间参数（参数3）设为 1.0——该步骤按 1 秒周期自动重复发送（执行时间第3.0秒，实际发送 3.0s、4.0s、5.0s…），**后续步骤不再重复编写触发步骤**。预期结果：软件接收一级指令，按对应 SPI 数据流定义组包，经 SPI 总线（当前 A 总线）向目标单板发送（**软件的 SPI 输出流不设计为测试步骤**，只在预期结果中描述）。触发载荷名逐字使用**上游数据流定义**的一级指令名：
   - **指令类**（SPI 输出流为控制指令，如机构控制指令/黑体驱动指令/开关指令）：一级触发即需求给定的上游遥控指令（如机构控制指令=遥控指令TCY216），一级指令名与软件经 SPI 下发的指令对应。
   - **轮询类**（SPI 输出流为电机/黑体/指令板轮询指令）：按需求判定软件自主轮询还是需外部触发，只有后者按 `<cross_requirement_context>`/上游数据流增加实际触发操作。一级“遥测帧轮询控制序列”仅用于回读验证，不得将其写成 SPI 轮询触发原因。
2. **SPI 模拟应答/遥测步骤（触发步骤之后的全部步骤）**：通过 **SPI 总线**发送对应**输入流**（数据流定义的 输入流N：XX应答/XX遥测数据）的数据，时间取触发周期后紧随的时刻（3.1s、4.1s、5.1s…）：
   - **载荷命名铁律**：逐字使用数据流定义的输入流名称——指令类模拟"机构控制指令**应答**"等应答流，轮询类模拟"电机遥测数据"等遥测流；**禁止泛化写法**（"返回应答数据包""正确的数据"）。
   - **站地址铁律**：SPI 数据帧以站地址寻址单板——步骤必须标注所模拟输入流定义中的站地址（如机构控制指令应答=站地址5BH），一个用例只对应一个单板，全部 SPI 步骤统一该站地址；**站地址错误**情形即改写该字段值，预期中站地址参数（TMYN230/W191）写**具体值**而非"应答中站地址"。
   - **正确应答/遥测**：预期写软件更新相应遥测帧（按需求给定）。
   - **字段错误应答/遥测**：按需求枚举错误类型（指令类：站地址、类型、LENGTH、DATA0、SUM；轮询类：站地址、类型、LENGTH、SUM），预期**必须写需求给定的错误计数/站地址参数的绝对值**（指令类 TMYN229/TMYN230，轮询类 W190/W191）——错误计数从初值 0 起按发生次序取 1、2、3…。**每类错误一个步骤**。
3. **节奏**：先一条"全部正确"建立基线；之后对每类字段错误按"**错误 → 正确**"交替——循环触发按周期自动重发，每类错误后一条正确恢复，再进入下一类错误。
4. **步骤时间**：首个业务步骤**从第3.0秒开始**；**禁止第0.0秒/第0秒**。

标准示例（指令类：机构控制指令，一级触发=遥控指令TCY216，模拟应答站地址5BH）：
```
(1) 第3.0秒，通过CANA总线以1秒为周期循环发送机构控制指令（遥控指令TCY216）；预期：软件接收，按机构控制电路数据流定义组包，经SPI总线A向滤光轮机构单板发送机构控制指令（循环时间=1.0，实际发送 3.0s、4.0s…）
(2) 第3.1秒，通过SPI总线发送站地址5BH的机构控制指令应答（全部字段正确）；预期：软件正常处理应答，SPI错误应答计数TMYN229保持0
(3) 第4.1秒，通过SPI总线发送站地址5BH的机构控制指令应答（站地址错误，其余字段正确）；预期：SPI错误应答计数TMYN229为1，SPI错误应答站地址TMYN230为该错误应答中实际填写的站地址具体值
(4) 第5.1秒，通过SPI总线发送站地址5BH的机构控制指令应答（全部字段正确）；预期：TMYN229保持1
（对其余字段错误 类型/LENGTH/DATA0/SUM 重复 错误→正确 交替；触发由步骤(1)按周期自动完成）
```

轮询类示例（软件自主轮询；一级周期回读相关遥测帧，SPI站地址取输入流定义，下例以XXH示意。若映射涉及多个遥测帧，逐帧设置回读，各自只声明一次循环）：
```
(1) 第3.0秒，通过CANA总线以1秒为周期循环发送〔对应遥测帧轮询控制序列的协议定义名〕；预期：软件返回对应遥测帧，供后续周期检查数据更新及错误计数；不触发或改变 SPI 自身轮询
(2) 第3.1秒，通过SPI总线发送站地址XXH的电机遥测数据（全部字段正确）；预期：软件更新相应遥测帧，SPI错误轮询计数W190保持0
(3) 第4.1秒，通过SPI总线发送站地址XXH的电机遥测数据（LENGTH错误，其余字段正确）；预期：W190为1，SPI错误轮询站地址W191为站地址XXH的具体值
(4) 第5.1秒，通过SPI总线发送站地址XXH的电机遥测数据（全部字段正确）；预期：W190保持1
```

### SPI总线自动切换小节（仅当需求含"自动切换/连续N次未收到同一节点正确遥测"时适用）

与二级CAN自动切换同构：软件初始经 SPI **A** 总线与单板通信，**连续 N 次**（按需求取值，如连续3次）未收到同一节点正确遥测数据时切换到 B 总线。**连续错误正是测试目的**，不适用逐错误配对交替；用例名/测试目的须含"自动切换"字样。步骤模式 = 上述循环触发 + SPI 遥测数据序列：
- **场景①未达阈值**：同一站地址的错误遥测数据连续 N-1 步，再 1 步全部正确（计数重置）；预期：SPI总线选择寄存器（21100014H）保持 A 总线选择值（0x0A）。
- **场景②达阈值**：同一站地址、同一字段错误连续 N 步；第 N 步预期：**SPI总线选择寄存器（21100014H）切换为 B 总线选择值（0x05）**——SPI 无转发总线可看，**切换判据就是选择寄存器状态**（通过监视内存地址读取），不得引入第二种指令做"验证总线"收尾步骤。

禁止（反例）：
- 把软件的 SPI 输出流（机构控制指令/轮询指令）写成测试步骤（输出流只出现在预期结果中；测试步骤只模拟输入流）；
- 遥测用例缺少一级周期回读，或把回读误作 SPI 轮询触发；需求明确需要外部触发时遗漏该独立触发操作；
- 以单板视角写步骤（"单板返回…"——测试系统通过 SPI 主动发送模拟返回）；
- SPI 步骤不标站地址，或预期中站地址参数写"应答中站地址"；
- 载荷泛化（"返回应答数据包"）或不用数据流定义的输入流名；
- 每个错误步骤后紧跟正确步骤恢复（自动切换场景②的连错必须连贯）；
- 首个步骤时间为第0.0秒。
