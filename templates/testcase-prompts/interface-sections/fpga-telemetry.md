# FPGA状态遥测接口(软件采集FPGA状态)专属规则——检测到 FPGA状态遥测 需求时注入

### FPGA状态遥测接口测试模型（强制，2026-09-08 用户拍板）

FPGA状态遥测接口的地址表**方向为输入**——测试系统通过**写内存模拟 FPGA 状态数据**，软件每秒采集这些地址并更新遥测。测试模型是**设置地址值 → 遥测轮询验证映射**：

1. **设置步骤**（按地址表逐地址一步）："第3.0秒，设置内存地址21143004H的数据为0x78123456"。设置值必须是**具体 32 位十六进制数**（字节边界清晰、便于位域映射，如 0x78123456、0xF1F2F3F4）——**禁止"FPGA GPS秒脉冲遥测数据（全部字段正确）"式标签载荷**。预期结果：相应地址值设置成功（如"内存地址21143004H的数据设置成功"）。
2. **遥测轮询步骤**（在全部设置步骤**之后**，时间递增）：设置值涉及几个遥测，就紧跟几个轮询步骤——如同时涉及遥测帧1与遥测帧3，则"第4.0秒，通过CANA总线发送遥测帧1轮询控制序列"与"第5.0秒，通过CANA总线发送遥测帧3轮询控制序列"各一步（单次发送，不写循环声明）。预期结果：对应遥测参数为设置值中**相应字段的映射值**——按地址表位域逐参数写出具体值（如设置 21143004H=0x78123456 → 遥测帧1参数W58（接收秒脉冲A计数）为0x12、W59（接收秒脉冲B计数）为0x34、W60（转发秒脉冲标识）为0x56）。
3. **时序铁律**：先设置后轮询；轮询步骤时间必须晚于最后一个设置步骤；同案多帧轮询按序编排。用例名/测试目的含"FPGA状态遥测"字样（同案多帧轮询的编排豁免混指令检查）。

标准示例（地址与位域映射取本需求地址表；两个输入地址、涉及遥测帧1与帧3）：
```
(1) 第3.0秒，设置内存地址21143004H的数据为0x78123456；预期：内存地址21143004H的数据设置成功
(2) 第3.5秒，设置内存地址21120028H的数据为0xF1F2F3F4；预期：内存地址21120028H的数据设置成功
(3) 第4.0秒，通过CANA总线发送遥测帧1轮询控制序列；预期：遥测帧1参数W58（接收秒脉冲A计数）为0x12、W59（接收秒脉冲B计数）为0x34、W60（转发秒脉冲标识）为0x56、W56（spacewire上注FPGA接收数据包数错误计数）为0xF1、W57（spacewire工作状态遥测）为0xF4
(4) 第5.0秒，通过CANA总线发送遥测帧3轮询控制序列；预期：遥测帧3参数W156（spacewire上注FPGA接收数据包数正确计数低字节）为0xF2、W157（spacewire上注FPGA接收数据包数正确计数高字节）为0xF3
```

禁止（反例）：
- 标签载荷："设置内存地址21143004H的数据为FPGA GPS秒脉冲遥测数据（全部字段正确）"（设置值必须是具体 32 位十六进制数，2026-09-08 取证纠错形态）；
- 把验证陈述写成发送/循环步骤："验证软件按1秒周期采集FPGA状态遥测…"（验证语义只能作为轮询步骤的预期结果，不是测试系统操作）；
- 轮询先于设置、或轮询时间早于设置步骤（时序颠倒）；
- 设置值涉及多个遥测却只轮询一个（涉及几个遥测就跟几个轮询步骤）；
- 预期中的映射值与设置值位域不一致（自洽性）；
- 首个步骤时间为第0.0秒。
