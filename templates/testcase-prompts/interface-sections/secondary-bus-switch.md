# 二级总线自动切换接口专属规则——检测到"自动切换/连续N次未收到正确/切换总线"时注入(依赖二级总线底座模型)

### 二级总线自动切换测试模型（强制）

被测行为：软件初始经二级总线**A**与节点通信，**连续 N 次**（按需求取值，如"连续3次未收到同一节点正确遥测数据则切换总线"的 N=3）未收到同一节点正确遥测数据时切换到另一条总线。**连续错误正是测试目的，不适用"错误后紧跟正确应答恢复"的交替节奏**（结构检查对自动切换主题用例豁免逐错误配对）。

步骤模式（**一级循环触发 + 二级遥测数据序列**，测试对象是"遥测数据"，故一级指令是遥测轮询）：

1. **循环触发步骤（唯一一条）**：第3.0秒，通过**一级总线**（按需求指定，如 CANA）**以1秒为周期循环发送遥测轮询控制序列**——一级总线的遥测轮询帧有4种（遥测帧1/2/3/4轮询控制序列），**任选其一**（如"遥测帧1轮询控制序列"）。**一级总线指令不带站地址**：轮询帧格式里的"80H+站地址"是帧内容，不是步骤载荷属性——站地址只出现在二级遥测数据步骤中。循环时间参数=1.0，实际发送时刻 3.0s、4.0s、5.0s…，**后续步骤不再重复编写触发步骤**。预期结果：软件接收并通过**二级总线A**向目标节点转发遥测轮询控制序列。**本步骤不可省略**——缺一级触发的用例会被结构检查拦截（触发与二级数据是同一测试的两半，只有二级数据的用例是半截用例）。
2. **二级遥测数据步骤**（时间取触发周期后紧随的时刻 3.1s、4.1s、5.1s…），按两个场景编排。**站地址**：从需求的二级总线数据流定义（站地址定义表）**选定一个从节点**，全用例统一该站地址（如"发送**站地址01H**的遥测数据（TITLE字段错误…）"）——"同一节点"即同一站地址：
   - **场景①未达切换阈值（不切换）**：同一节点（同一站地址）的错误遥测数据（任选一种字段错误，如 TITLE 错误）连续 **N-1** 步，再 1 步**全部正确**的遥测数据（重置连续错误计数）。这些步骤的预期结果都是：软件继续通过**二级总线A**输出遥测轮询控制序列（转发一级总线指令，未切换总线）。
   - **场景②达到切换阈值（切换）**：同一节点、同一种字段错误的错误遥测数据连续 **N** 步。前 N-1 步预期结果：软件继续通过**二级总线A**输出遥测轮询控制序列；**第 N 步预期结果：软件已切换总线，通过二级总线B输出遥测轮询控制序列**。

标准示例（N=3，TITLE错误，二级CAN，选定从节点站地址01H）：
```
(1) 第3.0秒，通过CANA总线以1秒为周期循环发送遥测帧1轮询控制序列；预期：软件接收并通过二级总线A向站地址01H的节点转发遥测轮询控制序列（循环时间=1.0，实际发送 3.0s、4.0s、5.0s…）
(2) 第3.1秒，通过二级总线A发送站地址01H的遥测数据（TITLE字节错误，其余字段正确）；预期：软件继续通过二级总线A输出遥测轮询控制序列（连续错误第1次，未达阈值不切换）
(3) 第4.1秒，通过二级总线A发送站地址01H的遥测数据（TITLE字节错误，其余字段正确）；预期：软件继续通过二级总线A输出遥测轮询控制序列（连续错误第2次，未达阈值不切换）
(4) 第5.1秒，通过二级总线A发送站地址01H的全部正确的遥测数据；预期：软件继续通过二级总线A输出遥测轮询控制序列（连续错误计数重置）
(5) 第6.1秒，通过二级总线A发送站地址01H的遥测数据（TITLE字节错误，其余字段正确）；预期：软件继续通过二级总线A输出遥测轮询控制序列（连续错误第1次）
(6) 第7.1秒，通过二级总线A发送站地址01H的遥测数据（TITLE字节错误，其余字段正确）；预期：软件继续通过二级总线A输出遥测轮询控制序列（连续错误第2次）
(7) 第8.1秒，通过二级总线A发送站地址01H的遥测数据（TITLE字节错误，其余字段正确）；预期：连续3次未收到同一节点正确遥测数据，软件已切换总线，通过二级总线B输出遥测轮询控制序列
```

要点：
- **用例名/测试目的必须含"自动切换"字样**——结构检查据此豁免连续错误的逐错误配对要求（连续错误是测试目的）。
- 切换阈值 N 严格按需求文本取值；场景①用 N-1 次连错 + 1 次正确（验证未达阈值不切换、计数可重置），场景②用 N 次连错（第 N 次触发切换）。
- 预期结果的**切换判据是软件转发遥测轮询控制序列所用的二级总线**（A=未切换，B=已切换）；错误遥测数据始终从二级总线A发送（切换是软件行为，测试系统不换发送总线）。
- 同一节点=同一站地址：从站地址定义表选定**一个从节点**（如站地址01H），**二级遥测数据步骤**统一标注该站地址（一级轮询触发步骤不带站地址）；两个场景用同一种字段错误即可（如 TITLE 错误），无需枚举全部错误类型。
- 广播数据 A、B 交替发送是另一独立行为（若需求包含，另设独立用例，不属于本模型）。

禁止（反例）：
- 每个错误步骤后紧跟正确步骤恢复（那是错误处理类用例的节奏；本模型场景②的连续错误必须连贯）；
- 错误遥测数据从二级总线B发送（测试系统始终从A发送，切换只体现在预期结果的转发总线上）；
- 逐周期重复编写一级触发步骤（循环触发步骤已按周期自动发送）；
- **追加"发送另一条指令验证总线仍正常工作"类收尾步骤**（如错误场景后补发遥控指令验证A/B总线）——切换判据只看预期结果中**转发遥测轮询控制序列所用的二级总线**，不需要也不应引入第二种指令；混入第二种指令会破坏用例"一条指令一个用例"的划分并被结构检查误判；
- 只写二级遥测数据步骤、不写一级循环触发步骤（没有一级轮询触发，二级遥测数据无从谈起——触发与数据是同一测试的两半，缺触发会被结构检查拦截并强制补齐）。
