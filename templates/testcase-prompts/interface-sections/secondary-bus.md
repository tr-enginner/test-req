# 二级总线(软件↔下位机)接口专属规则——检测到"二级CAN/二级总线"时注入

### 二级总线（软件↔下位机）测试模型（强制）

**回读、触发与方向分离（优先于下文通用循环触发规则）**：涉及遥测验证时，首先通过一级 CAN 周期发送对应的“遥测帧轮询控制序列”，用于读取并验证遥测更新值和错误计数，覆盖本用例所有相关遥测帧。默认第3.0秒开始、1秒周期，需求另有约定时以需求为准；同一帧只声明一次循环，不同帧分别设置。该回读不是软件二级 CAN 轮询触发，软件自主轮询不能豁免回读。触发软件自身轮询的步骤根据测试需要和需求依据另行添加。软件自主轮询时，按真实周期和节点顺序模拟二级输入，不得用一级回读周期替代节点轮询周期；只有明确由一级输入触发的转发才设置一级触发操作。软件的轮询/周期广播（如相机辅助数据）是输出，监测结论放在预期结果，不是测试系统发送动作；配置指令按需求发送，无应答协议时不制造应答步骤。

被测软件通过二级总线（如二级CAN）向**下位机**发送指令/数据并被动等待应答。测试视角铁律：**所有测试步骤都是测试系统主动发送**——一级总线侧发送指令触发软件转发，二级总线侧主动发送应答数据**模拟下位机的被动应答**（软平台测试环境没有下位机仿真组件，用主动发送模拟被动应答动作）。**禁止以下位机为参考视角编写步骤。**

需求上下文中出现"通过二级CAN总线发送XX指令/数据包"类描述时，涉及的每个指令/数据包设计一个用例，同一指令的不同情况（即使分散在不同 TR-ID 中，如应答错误计数与遥测轮询错误）**全部合并在同一用例中**。先设置周期遥测回读，以下转发触发模式仅在需求存在上游触发关系时适用，自主遥测采集不强加该触发：

1. **触发步骤（唯一一条，循环触发）**：通过**一级总线**（按需求指定，如 CANA）**以1秒为周期循环发送**一级总线数据协议中定义的指令/数据（名称与格式遵循需求的输入流和一级协议，如"遥测轮询控制序列""遥控指令"）。循环时间参数（参数3）设为 1.0——该步骤会以 1 秒为周期自动重复发送（执行时间第3.0秒，实际发送时刻为 3.0s、4.0s、5.0s、6.0s…），**后续步骤不再重复编写触发步骤**。预期结果：软件接收、解析，并按二级总线协议组装后经二级总线向下位机转发（协议组装与转发由软件内部完成，**不设计为测试步骤**，只在预期结果中描述）。**载荷协议层级铁律**：一级总线上发送的只能是**一级协议**的指令/数据——"二级CAN…"开头的协议名称（如"二级CAN遥测轮询控制序列"）属于二级总线协议，**禁止出现在一级总线发送步骤中**，它们只出现在二级总线的模拟应答步骤里。**一级指令不带站地址**：站地址只属于二级总线步骤（一级总线指令没有站地址；轮询帧格式里的"80H+站地址"是帧内容，不是步骤载荷属性——禁止写"发送站地址XXH的遥测帧N轮询控制序列"）。**长度限定词铁律**：数据流定义中同名指令有长度变体时（如"10字节遥控指令""15字节遥控指令"），触发步骤载荷必须带长度限定词**逐字使用定义名**——禁止裸写"遥控指令"；不同长度=不同格式，**每种长度独立一个用例**。**指令命名铁律**：一级触发步骤发送的指令名 = 二级侧转发的**具体指令名**（二级转发"遥控指令"，一级就发送"遥控指令"）——**禁止用"间接指令"等协议类别名替代具体指令名**；触发步骤与模拟应答步骤中的指令名必须一致，禁止"发送间接指令触发…发送遥控指令"这类名称漂移（名称漂移会破坏触发-应答关联，导致用例被结构检查误判拆散）。
2. **模拟应答步骤（触发步骤之后的全部步骤）**：通过**二级总线**发送该指令的应答，时间取触发周期发送后紧随的时刻（3.1s、4.1s、5.1s、6.1s…）：
   - **应答命名铁律**：应答步骤的载荷名必须使用**数据协议定义中与被转发指令配对的应答协议名**——指令是"遥控指令"，应答就是"遥控指令应答"；数据协议名称在需求的数据协议定义部分（如"遥控指令相关数据流"）都已定义好，**逐字使用定义名**。**禁止泛化写法**："应答数据包""正确的应答""返回正确的应答数据包"这类不含指令名的泛称一律错误——应答与指令名称不匹配会导致步骤割裂、无法对应测试功能。
   - **站地址铁律**：二级总线发送的指令/数据必须**指明站地址**——不同站地址对应下位机中的**不同从节点**，对应关系在需求的二级总线数据流定义（站地址定义表）中。一个用例只对应**一个从节点**（需求特别指明需要多从节点的除外）：从站地址定义表**随机选定一个从节点**，该用例全部二级步骤统一使用其站地址（写法如"发送**站地址01H**的遥控指令应答（仲裁场错误…）"），预期结果中的站地址参数写**该站地址的具体值**（如"二级CAN错误应答站地址TMYN396为01H"），不得写"该应答中站地址"之类的未定指代。
   - **正确应答**：预期结果写软件更新一级总线相应遥测（按需求给定）。
   - **字段错误应答**：按需求枚举错误类型（如仲裁场错误、控制场错误、LENGTH错误、TITLE错误、INDEX错误、SUM错误等），预期结果**必须写需求给定的错误计数/站地址遥测参数的绝对值**——错误计数从初值 0 起按错误发生次序取 1、2、3…，站地址参数写**选定站地址的具体值**。**每类错误一个步骤，不得合并为"某一字节错误"之类的泛化错误步骤**。
3. **节奏**：先用一条"正确应答"建立基线；之后对每类字段错误按"**错误应答 → 正确应答**"交替——循环触发步骤会按周期自动重发指令，每类错误后只需一条正确应答恢复正常，再进入下一类错误。（显式逐条触发——每个周期单独写一条触发步骤——也可接受，但**优先循环触发**，步骤更简洁。）
4. **步骤时间**：首个业务步骤**从第3.0秒开始**（软平台启动步骤占用前段）；**禁止第0.0秒/第0秒**——0 秒时刻属软平台初始化，业务步骤不得占用。

标准示例（10字节遥控指令，二级CAN，循环触发，选定从节点站地址01H；15字节遥控指令按同模式另立独立用例）：
```
(1) 第3.0秒，通过CANA总线以1秒为周期循环发送10字节遥控指令；预期：软件接收并通过二级CAN总线转发（循环时间=1.0，实际发送时刻 3.0s、4.0s、5.0s…）
(2) 第3.1秒，通过二级CAN总线发送站地址01H的正确的遥控指令应答；预期：软件接收并更新一级CANA相应遥测
(3) 第4.1秒，通过二级CAN总线发送站地址01H的遥控指令应答（仲裁场错误，其余字段正确）；预期：需求给定的错误计数绝对值，错误应答站地址TMYN396为01H
(4) 第5.1秒，通过二级CAN总线发送站地址01H的正确的遥控指令应答；预期：软件接收并更新一级CANA相应遥测
(5) 第6.1秒，通过二级CAN总线发送站地址01H的遥控指令应答（控制场错误，其余字段正确）；预期：需求给定的错误计数绝对值，错误应答站地址TMYN396为01H
(6) 第7.1秒，通过二级CAN总线发送站地址01H的正确的遥控指令应答；预期：软件接收并更新一级CANA相应遥测
（对每类字段错误重复 错误应答→正确应答 的交替；触发由步骤(1)按1秒周期自动完成）
```

生成后自检：逐条检查 CANA/CANB 发送步骤的载荷名称——**不得含"二级CAN"字样**（载荷协议层级错误）；"二级CAN"只应出现在"通过二级CAN总线发送…应答"步骤中；触发步骤与应答步骤的指令名**一致**（不得一边"间接指令"一边"遥控指令"）；应答步骤载荷**逐字使用数据协议定义的配对应答名**（"遥控指令应答"，不得泛化成"应答数据包"）；**每个二级发送步骤都指明站地址**且全用例同一站地址，预期中站地址参数为具体值（缺站地址会被结构检查拦截）；**一级总线发送步骤不带站地址**（站地址只属于二级步骤）；**有长度变体的指令必须带长度限定词**（"10字节遥控指令"，裸写"遥控指令"会被结构检查拦截，不同长度各立一个用例）；任何步骤时间**不得为第0.0秒**（首个业务步骤第3.0秒起）；触发步骤应为**唯一一条循环触发**（以1秒为周期循环发送），其后步骤全部是二级模拟应答（不再重复触发步骤）。

禁止（反例）：
- 把"软件通过二级总线向下位机转发指令"写成测试步骤（只出现在预期结果中）；
- 一级发送指令后在一级总线等应答（二级总线指令的应答在二级总线侧模拟发送）；
- 错误应答后不做"重新触发+正确应答"恢复，或各次错误之间不重新发送触发指令；
- 把同一指令的应答错误计数情况与遥测轮询错误情况拆到不同用例；
- 一级总线发送步骤的载荷写成"二级CAN××控制序列/指令/数据包"（载荷协议层级错——一级总线只发一级协议，二级协议只在二级总线模拟应答步骤中出现）；
- 触发步骤写"发送**间接指令**触发，触发软件通过二级CAN总线发送**遥控指令**"（命名漂移——一级发送的必须是被转发的具体指令本身，"间接指令"是协议类别名不是指令名；触发与应答指令名不一致会割裂两者的关联）；
- 应答步骤载荷写成"**返回正确的应答数据包**"（泛化错误——指令是"遥控指令"，应答必须逐字用数据协议定义的"**遥控指令应答**"，泛称使应答与指令失去对应）；
- 二级发送步骤不写站地址，或预期中站地址参数写"该应答中站地址"（站地址对应从节点，不指明站地址就无法确定测试的是哪个从节点；一个用例统一一个从节点的站地址）；
- **一级总线发送步骤写站地址**（如"发送站地址01H的遥测帧1轮询控制序列"——一级总线指令没有站地址，站地址只属于二级总线步骤；轮询帧格式里的"80H+站地址"是帧内容不是载荷属性）；
- 数据流定义中有长度变体的指令**裸写不带限定词**（"发送遥控指令"——定义里是"10字节遥控指令"和"15字节遥控指令"两种格式，不指明长度就无法确定测的是哪种，且两种长度应各立独立用例）；
- 首个步骤时间为"**第0.0秒**"（0 秒属软平台初始化；业务步骤从第3.0秒起逐步骤递增）。
