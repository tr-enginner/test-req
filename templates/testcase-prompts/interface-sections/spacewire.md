# Spacewire总线(软件↔星务上注)接口专属规则——检测到 Spacewire 上注数据块/中断触发需求时注入

### Spacewire 上注数据块测试模型（强制）

Spacewire 总线不是测试系统直接发送帧的总线接口：被测软件通过集成在 FPGA 的 Spacewire 总线接口**被动接收**星务上注的数据。测试环境没有星务仿真组件，由**测试系统按三步流程主动模拟一次上注数据交付**——每个数据块的发送都是一组固定三步（地址、ID、中断的取值逐字使用本需求"输入流/地址表"定义与**中断上下文**原文，禁止编造）：

1. **第一步·写协议数据**：将数据块的协议数据写入**上注数据块地址**（地址表定义，如 21142000H~211422CFH）。
2. **第二步·写数据 ID**：将该数据块对应的 ID 写入 **ID 地址**（地址表定义，如 21142E00H；ID 取值按数据流定义，如 2501H=管控程序上注、2502H~2511H=二级节点上注）。
3. **第三步·触发中断**：触发 Spacewire 相应**外部中断**——从提示的**中断上下文**表中选取"执行功能"为 spacewire 总线中断的行，取其中断名称（如"外部中断2"），步骤写"第N秒，触发外部中断2"（中断号逐字取上下文原文，禁止编造，禁止只写"触发Spacewire外部中断"不带号）。

**步骤措辞铁律（与关键字库对齐）**：
- 写数据步骤写"第N秒，设置内存地址<地址>的数据为"<块名>·<情况>""（对应关键字 设置32位地址数据）；写 ID 步骤同形态，地址用 ID 地址、数据写 ID 值。
- 中断步骤写"第N秒，触发外部中断<中断号>"（对应关键字 触发外部中断）。
- **禁止罗列"W2=01H、W3=00H"式字段值清单**（字段取值由执行阶段的数据文件承载）；第N秒、内存地址等单值操作性参数保留。
- 首个业务步骤**从第3.0秒开始**，禁止第0.0秒。

### 数据块序列编排（强制）

**上注类型独立用例铁律**：管控程序上注与二级节点上注是**不同的上注数据块类型/ID 族**（如 2501H=管控程序、2502H~2511H=二级节点程序），测试目的不同——**必须分别独立成用例，一个用例只覆盖一种上注类型**（二级节点同族的不同 ID 可合并在同一个用例中覆盖）。混排会被结构检查拦截并要求重派。

上注数据块序列由数据流定义，逐字使用其块名与字段名：

- **起始块**：唯一 1 个（如管控程序上注 W3=00H）；
- **中间块**：可以多个（如 W3=05H），按测试需要发送合适数量；
- **校验块**：唯一 1 个（如 W3=0AH），**序列的最后一块**。
- 每个数据块的发送都独立走完上述三步（写协议数据→写ID→触发中断）。
- 有效字段按数据流定义枚举（如管控程序上注起始/中间块：包标识、包类型、起始地址、数据长度、有效数据、ISO校验；校验块另有校验和）。

### 字段错误编排铁律（2026-09-02 拍板）

- **每个数据块的"全部字段正确"情况整个用例只发送一次**——正确情况不允许重复发送同一数据块。
- **正确块与字段错误块交替推进**：发送正确的某块后，紧随发送**另一字段错误**的同名块（错误块被软件检出并计数，不进入有效序列）；随后进入下一块的"正确→错误"循环，直到以**正确的校验块收尾**——此时完整的上注数据块集合被软件接收（每个块都恰好正确交付一次）。
- **块数量不足以覆盖全部字段错误时**：对**同一数据块连续发送不同字段的错误块**，把剩余字段错误情况覆盖完毕，之后以**一个正确的最后数据块（校验块）结尾**。
- **正确的校验块之后禁止再发任何错误块**——校验块收尾后序列已完整，后续错误块与前面序列失去关联，等效于在新用例开头孤立发送（属步骤拆散无效行为）；剩余错误情况必须安排在正确校验块**之前**。
- 字段错误步骤写"（XX字段错误，其余字段正确）"标注形态；预期结果写需求给定的错误计数绝对值（如"spacewire上注CPU接收数据包错误计数"遥测帧3参数 TMYN383 按发生次序取 1、2、3…）。
- **非法 ID 单独作为一个用例**：ID 不在数据流定义范围（如非 2501H~2511H）时软件不进入上注处理、错误计数加 1——此场景独立用例，不与正常序列混排。

标准示例（5 块 × 6 字段：起始块、中间块1~3、校验块；字段记为 A~F，实际取数据流定义字段名；每块三步在此仅示意第一块，其余块同样三步）：
```
(1) 第3.0秒，设置内存地址21142000H的数据为"管控程序上注起始块·全部字段正确"；(2) 第3.1秒，设置内存地址21142E00H的数据为"2501H"；(3) 第3.2秒，触发外部中断2（中断号取中断上下文表中执行功能为 spacewire总线中断 的行）；预期：起始块正确接收，错误计数保持0
(4~6) 第4.x秒，同三步发送"管控程序上注起始块·A字段错误，其余字段正确"；预期：起始块被检出错误，TMYN383加1
(7~9) 第5.x秒，同三步发送"管控程序上注中间块1·全部字段正确"（不可再重复正确的起始块）；预期：中间块1正确接收
(10~12) 第6.x秒，同三步发送"管控程序上注中间块1·B字段错误，其余字段正确"；预期：TMYN383再加1
（中间块2/3 依此类推；若剩余字段错误多于剩余数据块——例如还差 E、F 两处——则在最后一个中间块上连续发送"E字段错误""F字段错误"两块，再以正确的校验块收尾）
(最后三步) 第N.x秒，同三步发送"管控程序上注校验块·全部字段正确"；预期：完整上注数据块集合被软件接收
```

禁止（反例）：
- 不写三步、直接写"发送上注数据块"（缺地址/ID/中断任一步，软件不会读取数据）；
- 在一个步骤里罗列"W0~W1=0000H、W2=01H…"式字段值清单；
- 同一数据块的"全部字段正确"情况发送两次；
- 正确校验块之后再追加字段错误块（序列已完整，后发错误块成孤立步骤）；
- 中断号/向量编造或只写"触发Spacewire外部中断"不带号（必须逐字取中断上下文原文，如"触发外部中断2"）；
- 管控程序上注与二级节点上注混排在同一用例（不同上注类型必须拆分为独立用例）；
- 非法 ID 场景混入正常序列用例；
- 首个步骤时间为第0.0秒。
