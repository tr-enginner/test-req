# 秒脉冲接口(软件↔FPGA 转发)专属规则——检测到 秒脉冲+切换 需求时注入

### 秒脉冲接口测试模型（强制，2026-09-02 用户拍板）

秒脉冲接口的数据流定义虽给出地址（如 21143000H），但该地址属于**输出流**——软件收到秒脉冲切换指令后通过该地址输出秒脉冲切换方式的监视地址，**不是测试系统的写内存输入**。测试模型是**一级总线遥控指令收发**：

1. **步骤形态**："第N秒，通过CANA总线发送正确的秒脉冲信号切换指令"。秒脉冲信号切换指令是**遥控指令**——上下文未给出具体指令代号与字段编码，载荷名逐字写"秒脉冲信号切换指令"，**禁止编造指令代号，禁止编造"AAAAH（切换GPSA）"式载荷或字段值**（字段取值由执行阶段的数据文件承载）。
2. **字段错误遍历（W0~W9）**：对遥控指令的 W0~W9 字段逐一测试错误形态："第N秒，通过CANA总线发送秒脉冲信号切换指令（W0字段错误，其余字段正确）"……每个字段各一步；**正确-错误交替**——每个错误步骤后紧跟一条正确的秒脉冲信号切换指令步骤恢复（结构检查按同指令同总线配对判定，交替缺失会被拦截）。
3. **预期结果**：所有步骤一律"软件通过CANA总线返回遥控指令应答"；**发送正确指令的步骤额外写"通过地址21143000H输出对应的秒脉冲切换方式"**（地址逐字取本需求输出流定义；切换方式的具体取值由软件行为决定，不在预期中罗列字段值）。
4. 首个业务步骤**从第3.0秒开始**，禁止第0.0秒。

标准示例（地址取数据流定义值，下例以 21143000H 示意；W0~W9 仅示意前两字段，其余同理）：
```
(1) 第3.0秒，通过CANA总线发送正确的秒脉冲信号切换指令；预期：软件通过CANA总线返回遥控指令应答，通过地址21143000H输出对应的秒脉冲切换方式
(2) 第4.0秒，通过CANA总线发送秒脉冲信号切换指令（W0字段错误，其余字段正确）；预期：软件通过CANA总线返回遥控指令应答
(3) 第5.0秒，通过CANA总线发送正确的秒脉冲信号切换指令；预期：软件通过CANA总线返回遥控指令应答，通过地址21143000H输出对应的秒脉冲切换方式
(4) 第6.0秒，通过CANA总线发送秒脉冲信号切换指令（W1字段错误，其余字段正确）；预期：软件通过CANA总线返回遥控指令应答
（W2~W9 依此类推：每个字段错误一步，错误后紧跟一步正确指令恢复）
```

禁止（反例）：
- 把输出流地址写成写内存步骤："第3.0秒，设置内存地址21143000H的数据为AAAAH（切换GPSA）"（输出流地址不是测试系统的写内存输入，2026-09-02 取证纠错形态）；
- 编造指令代号或载荷字段值（"AAAAH""BBBBH""切换GPSA"等取值由执行阶段数据文件承载）；
- 错误步骤后不跟正确恢复步骤（正确-错误交替是硬约束，会被结构检查拦截）；
- 正确指令步骤的预期漏写"通过地址21143000H输出对应的秒脉冲切换方式"；
- 首个步骤时间为第0.0秒。
