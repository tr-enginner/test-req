# 有序多包测试模型（含249字节上行数据块、双辅助数据包）

本模型优先于一级 CAN 的“错误后重发同一正确包”通用规则。包序号与包内帧序号是两个维度：每个正确包必须包含格式表规定的全部帧；错误包除指定的单字段或单类帧序号错误外，其余部分正确。

## 正确包推进与错误分摊

1. 功能、接口、数据处理和强度测试统一遵循本模型；强度测试仍保持一个综合用例，其余类型按各自规则划分。依据真实协议确定总包数n，不得用第一、第二、最后三个代表包省略必需的中间包；双辅助数据包的n为2。
2. 基本顺序为“完整正确包1→包1单字段错误→完整正确包2→包2另一单字段错误→…→完整正确包n”。每个步骤只发送一个完整包。滤掉错误包后必须恰为包1至包n，不跳包、不重复正确包。
3. 先从输入协议表和处理条款建立错误覆盖清单：首帧/中间代表帧/尾帧的适用字段，以及适用的帧重复、序号错误、丢失。仲裁场和控制场分别覆盖；LENGTH、TITLE 仅在实际出现的位置覆盖，SUM 按尾帧定义覆盖。
4. 所有包共同分摊错误清单，不要求每包穷举；错误项多于前n-1包的交错位置时，在正确包n之前，使用包n逐步验证剩余未测错误，允许这部分连续错误。末包不含待测字段时必须依据真实格式另行安排并反馈约束冲突，不得编造字段。
5. 错误已覆盖完时，剩余包连续正确发送。最终必须以完整正确包n收尾，验证完整业务响应，不能以末包错误结束，不能为覆盖字段重复启动第一包。仅需求明确要求多轮运行时才重复完整业务序列。
6. 正确步骤明确包号和“完整多帧、全部字段正确”；错误步骤明确包号、代表帧和唯一错误字段。帧数从实际格式表读取，不能根据字节数猜测。

## 预期结果

完整正确包按需求处理、应答、存储，正确计数递增；错误包不执行对应处理，正确计数不变，需求规定的格式错误计数或错误指令计数递增。各计数写出连续的绝对值。最后一包还须检查整组有效数据的业务结果及总校验结果。不得假设被丢弃的错误包进入业务拼接序列。

双辅助数据包不再采用旧四步循环：正确包1→包1一个错误→包2剩余错误逐项发送→完整正确包2。该规则优先于通用错误后立即重发同一正确包的约束。
