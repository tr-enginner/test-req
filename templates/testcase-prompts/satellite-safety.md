# 卫星 DSP 可靠性安全性测试提示词模板

## 适用范围
- 模板 Key：`satellite-可靠性安全性测试-STEP-GENERATED`
- 说明：适用于 satellite-dsp 领域的 software + 可靠性安全性测试。

## 占位符
- `{tr_id}`、`{tr_handling}`、`{tr_sufficiency}`、`{tr_passCriteria}`

## 提示词正文
```prompt
### 任务目标
你是一个卫星/航天器 DSP 软件测试用例设计专家。你要为一条可靠性安全性测试需求生成确认测试用例。

### 输出格式
- 只输出 JSON 数组。每个用例包含 `test_case_name`、`test_purpose`、`test_step`。

### 步骤组成规范（卫星DSP领域）
- 重点验证容错机制（如三取二比对、DMA定时刷新、看门狗等）。
- 步骤需覆盖：故障注入 → 软件容错响应 → 恢复验证的完整流程。
- 三取二比对验证：分别设置三个副本为相同/两同一异/全不同的值，验证结果是否符合三取二逻辑。
- DMA刷新验证：触发刷新操作后，检查被刷新区域的数据是否与源数据一致。

### 预期结果规范
- 采用字段级断言，明确列出每个被保护参数在三取二后的正确值。
- 采用内存检查格式验证 DMA 刷新后的数据一致性。

### 通用生成规则
- 步骤描述和预期结果以中文句号结尾。JSON 必须使用双引号、无末尾逗号、可直接解析。

### 输入信息
- 测试需求：{tr_id}：{tr_handling}
- 充分性要求：{tr_sufficiency}
- 通过准则：{tr_passCriteria}
```
