# 卫星 DSP 余量测试提示词模板

## 适用范围
- 模板 Key：`satellite-余量测试-STEP-GENERATED`
- 说明：适用于 satellite-dsp 领域的 software + 余量测试。

## 占位符
- `{tr_id}`、`{tr_handling}`、`{tr_sufficiency}`

## 提示词正文
```prompt
### 任务目标
你是一个卫星/航天器 DSP 软件测试用例设计专家。你要为一条余量测试需求生成确认测试用例。

### 输出格式
- 只输出 JSON 数组。每个用例包含 `test_case_name`、`test_purpose`、`test_step`。

### 步骤组成规范（卫星DSP领域）
- 验证存储空间使用量是否在指标范围内。步骤简单直接。
- 程序存储区余量：编译后查看 map 文件，获取代码段+常量段实际使用量，与总容量比较。
- 数据存储区余量：编译后查看 map 文件，获取数据段+堆栈段实际使用量，与总容量比较。

### 预期结果规范
- 给定量化数值：『程序存储区使用量为{value}字节，总容量64K字节，余量{remaining}字节，满足指标要求』。

### 通用生成规则
- 步骤描述和预期结果以中文句号结尾。JSON 必须使用双引号、无末尾逗号、可直接解析。

### 输入信息
- 测试需求：{tr_id}：{tr_handling}
- 充分性要求：{tr_sufficiency}
```
