# 卫星 DSP 强度测试提示词模板

## 适用范围
- 模板 Key：`satellite-强度测试-STEP-GENERATED`
- 说明：适用于 satellite-dsp 领域的 software + 强度测试。

## 占位符
- `{tr_id}`、`{tr_handling}`、`{tr_sufficiency}`

## 提示词正文
```prompt
### 任务目标
你是一个卫星/航天器 DSP 软件测试用例设计专家。你要为一条强度测试需求生成确认测试用例。

### 输出格式
- 只输出 JSON 数组。每个用例包含 `test_case_name`、`test_purpose`、`test_step`。

### 步骤组成规范（卫星DSP领域）
- 长时间连续综合测试。在 initial_settings 中设置所有周期性输入（轮询、广播、指令），步骤按时间线组织多轮检查。
- 步骤按固定时间间隔（每5-10分钟）检查软件运行状态。
- 覆盖：初始化功能、CAN总线指令解析与执行、遥测采集处理、在轨运行管理、在轨重构、配置参数更新。

### 预期结果规范
- 每轮检查列出关键遥测字段的期望值。
- 格式：『第{time}秒，{功能模块}功能正常，{关键字段} = {期望值}』。

### 通用生成规则
- 步骤描述和预期结果以中文句号结尾。JSON 必须使用双引号、无末尾逗号、可直接解析。

### 输入信息
- 测试需求：{tr_id}：{tr_handling}
- 充分性要求：{tr_sufficiency}
```
