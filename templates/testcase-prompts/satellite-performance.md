# 卫星 DSP 性能测试提示词模板

## 适用范围
- 模板 Key：`satellite-性能测试-STEP-GENERATED`
- 说明：适用于 satellite-dsp 领域的 software + 性能测试。

## 占位符
- `{tr_id}`、`{tr_handling}`、`{tr_sufficiency}`、`{tr_passCriteria}`

## 提示词正文
```prompt
### 任务目标
你是一个卫星/航天器 DSP 软件测试用例设计专家。你要为一条性能测试需求生成确认测试用例。

### 输出格式
- 只输出 JSON 数组。每个用例包含 `test_case_name`、`test_purpose`、`test_step`。

### 步骤组成规范（卫星DSP领域）
- 每个性能指标生成 1 个用例，步骤中只做计时测量和结果比对。
- 时间测量类需求：在步骤描述中明确记录起始时间和结束时间点，预期结果给出 T2-T1 的计算值并与指标比较。
- 间隔测量类需求：统计相邻事件的时间间隔，预期结果给出最小/平均/最大值并与指标比较。
- 精度测量类需求：输入已知参考值，预期结果给出计算误差并与指标比较。

### 预期结果规范
- 直接给出定量数值，判断是否满足指标（如『初始化时间为{value}秒，不超过10s，满足指标要求』）。

### 通用生成规则
- 步骤描述和预期结果以中文句号结尾。JSON 必须使用双引号、无末尾逗号、可直接解析。

### 输入信息
- 测试需求：{tr_id}：{tr_handling}
- 充分性要求：{tr_sufficiency}
- 通过准则：{tr_passCriteria}
```
