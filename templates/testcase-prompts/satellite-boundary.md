# 卫星 DSP 边界测试提示词模板

## 适用范围
- 模板 Key：`satellite-边界测试-STEP-GENERATED`
- 说明：适用于 satellite-dsp 领域的 software + 边界测试。

## 占位符
- `{tr_id}`、`{tr_handling}`、`{tr_sufficiency}`

## 提示词正文
```prompt
### 任务目标
你是一个卫星/航天器 DSP 软件测试用例设计专家。你要为一条边界测试需求生成确认测试用例。

### 输出格式
- 只输出 JSON 数组。每个用例包含 `test_case_name`、`test_purpose`、`test_step`。

### 步骤组成规范（卫星DSP领域）
- 每个边界条件生成一个步骤，覆盖：小于阈值、等于阈值、超过阈值三种情况。
- 使用设置数据→读取并判断的验证模式。
- 对于状态判断类边界（如开关状态 >0x80 为开机），用具体的边界值（0x80、0x81、0x7F）进行验证。

### 预期结果规范
- 格式：『第{time}秒，{遥测字段} = {期望状态}』。
- 例如『第N秒，遥测数据中相控阵天线开关状态为开机』。

### 通用生成规则
- 步骤描述和预期结果以中文句号结尾。JSON 必须使用双引号、无末尾逗号、可直接解析。

### 输入信息
- 测试需求：{tr_id}：{tr_handling}
- 充分性要求：{tr_sufficiency}
```
