# 证据与范围

成立的数据处理需求必须同时具备：

- 明确的数据对象，例如遥测数据、传感器值、参数、数据帧、状态量、控制字或计算结果；
- 以数据内容质量或通用表示预处理为主要验证对象，并能脱离具体业务功能独立验证；
- 原文可追溯的输入来源或处理依据；
- 可验证的处理结果，例如更新某参数、生成某输出、丢弃无效数据、得到融合值或解释为某状态。

以下内容不写入4.7：

- 纯接口传输格式、通信方向、帧格式或协议解析，归4.3接口测试；
- 纯时间、周期、响应、精度或性能指标，归4.2性能测试；
- 纯范围、阈值、上下限、端点或边界值处理，归4.6边界测试；
- 纯业务功能动作，没有明确数据处理链路，归4.1功能测试；
- 文件位置选择、业务持久化、缓冲区寻址、烧录地址计算或写入控制，归4.1功能测试；
- 帧ID、长度、校验和或格式合法性及非法帧丢弃，归4.3接口测试；
- 协议组帧/解帧、增加包头、字段路由或原样转发，归4.3接口测试；
- 接收广播、报文或应答，以及协议解析和字段提取，归4.3接口测试；
- 经纬高、位置速度等数值范围、上下限和端点合法性，归4.6边界测试；
- 定位标志、状态字、帧字段或协议合法性，归4.3接口测试；
- 坐标系转换、姿态矩阵、角度修正、指向计算、相位计算、控制码生成及任务核心姿态、轨道、导航或控制算法，归4.1功能测试；
- SRAM、文件、缓存和内部变量中的业务暂存、定时读取或后续计算准备，归4.1功能测试；
- 纯安全可靠性、恢复、余量或强度描述，归对应章节；
- 只有“处理数据”“进行计算”等泛化表述，但没有数据对象、依据和结果。

不得用常识补造原文没有的数据源、算法、阈值、单位、存储对象、输出结果或异常处理行为。

典型保留：明确从传感器或采集通道主动采样并验证结果；独立的单位、量纲、基础编码、数值格式或标准化转换；重复、过期、异常测量样本清洗；多个独立数据源形成综合测量结果。复合语句删除接口、边界和核心功能部分后若不再形成独立通用预处理链路，整项排除。
