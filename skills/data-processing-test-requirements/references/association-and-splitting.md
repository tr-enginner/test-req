# 关联与拆分

## 合并

满足以下条件时可以合并为一个row：

- 同一数据对象或同一数据块；
- 同一处理阶段或同一处理链路；
- 输入来源、处理依据和可验证结果一致；
- 主要分类一致。

例如同一遥测帧中多个参数都由同一次采集返回并更新，且测试目的都是验证返回数据用于更新参数，可以合并。

## 拆分

出现以下情况必须拆分：

- 数据对象不同，且验证结果不同；
- 一个描述中同时包含采集、转换、剔除、融合、解释等不同主要验证意图；
- 输入来源、处理依据、算法或输出结果不同；
- 一部分属于4.7，另一部分属于接口、性能、边界、功能或安全可靠性章节。

关联前固定按4.3接口协议→4.6边界→4.1核心功能→4.7数据处理裁决。删除接口、边界和核心功能步骤后，若剩余部分不能脱离具体业务独立回答“输入数据是什么、执行什么通用预处理、可验证数据结果是什么”，整项排除，不得为了匹配五类枚举而保留空壳描述。

## 去重

全文重复需求只保留首次出现且信息最完整的一条。若两处描述互相冲突，不自行选择，写入`open_questions`。

普通排除项直接忽略，不写`open_questions`；只有引用缺失、决定分类的关键原文缺失、处理依据缺失或原文冲突才记录问题。
