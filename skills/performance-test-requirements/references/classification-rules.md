# 性能类型分类规则

- **时间间隔**：两个同类或关联事件、数据帧、指令之间具有可验收边界的间隔、周期或频率，例如周期上限、频率下限或帧间隔范围。多帧之间的时间空隙归入此类。
- **处理时间**：初始化、计算、装载、转换、组帧等一次操作从开始到完成的持续时间。
- **处理精度**：时间测量或时间控制的允许误差、偏差、分辨率、抖动或 `±` 容差。普通计算结果精度不属于此类。
- **响应时间**：外部刺激、请求或指令出现到应答、响应或输出产生之间的时间。

一项需求只能选择一个主要类型。若一句原文包含两个可独立测试的时间关系，应拆为两项。

## 先判定是否属于性能

分类只能在候选已经形成外部可观察、可判定的性能边界后进行。以下内容不得仅凭时间单位或周期/频率关键词归为“时间间隔”：

- 软件定时器、任务、中断或计数器的固定周期；
- “每X时间执行、采集、更新或发送一次”的实现节拍；
- 数据包长度、轮询方式、更新节拍等设计或协议配置。

固定值若同时具有误差、抖动、稳定性或实际周期准确性要求，只提取该可验收性能边界；固定值本身作为必要上下文，不另建需求。
