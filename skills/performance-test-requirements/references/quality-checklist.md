# 质量检查表

输出前逐项确认：

- 测试对象和动作是否明确；
- 触发或起止事件是否足以理解时间关系；
- 数值、单位和比较关系是否来自原文；
- 上限、下限、平均值和容差是否完整；
- 分类是否符合语义而不是照抄章节名称；
- 是否仅因出现时间单位、周期或频率关键词就错误生成需求；
- 该TR验证的是外部可观察的时间能力或验收边界，还是只重复软件定时器、任务、中断、计数器、采集/更新/发送节拍等设计配置；
- 隐含需求是否确实可量化；
- 是否误收日期、版本、功能、接口、安全可靠性或普通数值精度；
- 是否与其他条目重复，或可与同类指标合并；
- 描述是否能直接进入表4.2-1。
- 明确排除的固定调度/设计约束是否未生成row，并以“已排除”格式记录了canonical来源和理由。
