# 关联、合并与拆分

- 同一独立存储区的名称、地址/地址范围、总量、最大使用量和占用比例合并为一行。
- 同一任务的时间预算、最大耗时和允许占用比例合并为一行。
- 同一通道的最大吞吐能力、峰值流量和负载限制合并为一行。
- PROM、MRAM、SRAM、Flash、栈、堆、文件区等不同介质必须拆分；同一介质的多个命名区或独立地址范围也必须拆分。不得用“各存储区”合成一条，即使它们共享同一余量比例。
- 原文明示适用于全部存储区的统一余量要求，应分别关联到每个明确存储区；不得因此合并这些row。
- 不同处理任务、输入输出方向、通道或约束类型拆分。
- 全文重复指标保留信息最完整的一项，并维持首次出现顺序。
