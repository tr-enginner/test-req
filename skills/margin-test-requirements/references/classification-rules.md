# 分类规则

- `存储量的余量`：PROM、MRAM、SRAM、Flash、栈、堆、文件区等独立存储区的容量/地址与最大使用量、占用比例或剩余空间的关系。同一介质的多个命名区或独立地址范围也不得合并；地址不得用于计算未明示容量。
- `功能处理时间的余量`：原文明示的时间余量、预留比例或时间预算占用上限。普通中断/任务周期、截止时间、响应时间或最大处理耗时属于性能需求，不得通过差值或比值推导余量比例。
- `输入/输出及通道的吞吐能力余量`：接口、总线、通道或队列最大能力与可施加峰值负载、明确余量阈值及可观察吞吐/占用统计口径之间的关系，四类证据缺一不可。

同一描述覆盖多类时，按主要受约束资源分类；独立资源约束应拆分。

反例：`1553B接口速率为1Mbps，要求保留20%余量`缺少峰值业务负载和观测口径，不生成row。正例：原文同时给出1Mbps能力、可施加的峰值流量、占用不超过80%及吞吐统计方法时，可生成吞吐余量row。
