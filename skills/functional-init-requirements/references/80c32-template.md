# 80C32 初始化模板与输出规则

识别到 80C32 时，必须参考以下示例，并逐字保留全部七行及其顺序：

```
80C32 初始化设置

| 寄存器名称 | 设置 | 含义 |
|---|---|---|
| IE（允许中断寄存器） | 00H→8FH | 允许外部中断0、外部中断1、定时器0中断、定时器1中断，禁止串口中断、T2中断。 |
| IP（中断优先级寄存器） | 05H | 外部中断0、外部中断1的中断优先级为高，定时器0、定时器1中断优先级均为低 |
| TMOD（定时器模式寄存器） | 11H | 定时器1、定时器0均工作在16位定时器模式 |
| TCON（定时器控制寄存器） | 00H→50H | 启动定时器1、定时器0，外部中断1、外部中断0均低电平触发 |
| PCON（电源管理寄存器） | 0x80 | 波特率加倍 |
| TH1、TL1（定时器1寄存器） | TH1=0x4C，<br>TL1=0x00 | 定时器1定时时间为50ms |
| TH0、TL0（定时器0寄存器） | TH0=0xEE，<br>TL0=0x00 | 定时器0定时时间为5ms |
```

映射到初始化需求现有四列表格时：

- `寄存器名称` 映射为 `名称`。
- `设置` 映射为 `初值`。
- `含义` 映射为 `初值含义`。
- 模板未提供 `地址/寄存器地址`，该列统一填写 `XX`。

一个 80C32 只生成一个 CPU processing 和一张四列汇总表。IE、IP、TMOD、TCON、PCON、TH1/TL1、TH0/TL0 全部归入该 CPU 表，不得将片上定时器拆成独立 TR 或独立表。项目来源明确覆盖某个模板值时采用项目实际值；来源未明确时保留该模板行并用 `XX` 替代无法确认的地址、初值或必要含义，不得把示例值无条件视为所有项目的事实。
