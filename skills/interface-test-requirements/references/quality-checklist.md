# 质量检查表

- 接口名称和标识能在硬件接口文本中定位，总线、节点和站地址未串线。
- 通信方向、发送方、接收方与原文一致；无法确认时不得编造。
- 当前接口标识下每个外部输入、输出方向均已检查正常和异常情况；未形成需求的方向已说明原因。
- 每个row已核对正文与`related_description`覆盖范围一致；正文未描述异常条件和响应时，相关说明未声称覆盖正常/异常。
- 正常和异常证据属于同一事务时已合并在同一row；未机械拆成正常TR和异常TR。
- 只有正常证据时已保留正常需求、将相关说明限定为正常情况，并在`open_questions`写明异常条件或异常响应缺口。
- 只有异常证据时相关说明只声明异常测试，未虚构正常行为。
- 已检查协议传输、内容、解析、先后关系及超时后的功能处理；纯传输时间、周期、帧间隔、延迟、抖动、吞吐和速率指标未进入4.3。
- 每行的主要断言是接口格式、内容、交互、容错或状态处理，而不是定量时间/速度指标。
- 混合要求已剥离性能阈值；剥离后已被其他事务覆盖的接口行为未重复生成。
- 已按主要验证对象排除安全性/可靠性要求；仅出现接口名称或接口标识未被当作纳入4.3的依据。
- 已排除有效接收后的计算、业务处理、内部状态管理和存储；未定义输出接口、接收方及格式的转发未进入4.3。
- 混合要求剥离功能和性能内容后，剩余ID识别或格式解析若已被其他接口项覆盖，已整项排除。
- 接收后的输出只有在输出接口、接收方、消息/信号和格式规则明确时才作为跨接口事务保留。
- bus-off、硬件状态寄存器异常、控制器复位/重新初始化、故障隔离、冗余重构和自动恢复未进入4.3。
- 混合要求若主要目的仍是故障管理或恢复，已整项排除，而不是删去故障词后改写成接口需求。
- `related_description` 未使用“接口传输时间/周期/响应时间/帧间隔性能”等性能测试范围。
- 已检查外部干扰、丢帧、错帧、误码和非法内容；只保留原文明示的异常模式与容错动作。
- 已检查接口数据特性、错误特性、速度特性对软件功能和性能的影响。
- CAN 接口已按 `can-interface-coverage.md` 检查明确的总线实例、全部输入流、实际格式字段、多帧异常、事务隔离及有证据的高优先级广播；非 CAN 接口未套用 CAN 字段。
- 请求—应答需求是否只保留请求/应答名称、真实格式表号、正常应答、明确错误字段及错误应答/不应答/丢弃。
- 是否删除了接收后的解析暂存、计算、业务执行、模式切换、内部状态、存储、内部错误计数和日志。
- 错误字段或异常类型是否逐项列出，未使用“相关字段”“格式错误”“异常情况”等模糊省略。
- 单向广播或遥测上报是否只保留发送消息、接收方和第三章表号，未补造应答、周期或对端处理。
- 同一次轮询、查询或控制的请求与响应未因方向相反或报文不同而机械拆成两项。
- 相同处理流程下仅ID、地址、长度、索引、数据块或来源不同的变体已经归并，并逐项保留差异。
- 已对候选行做成对比较，不存在接口标识、业务目标、处理结果和相关说明高度重叠的重复行。
- 每一行代表一个完整事务、一个同类处理族或一个确有独立结果的行为，而不是单个报文片段。
- 只保留单帧、字段、应答或单次事务层面的外部可观察响应；内部错误计数、日志、业务处理及硬件或链路故障恢复未保留。
- 冗余接口只保留正常数据选择和传输契约；故障检测、隔离、重构和恢复已转交安全性/可靠性测试。
- 简单信号接口未虚构消息帧字段。
- 没有编造章节号、表号、字段、阈值或协议规则。
- 没有用“等”“相关字段”省略必须列举的内容。
- 找不到被引用表格或双方信息时，已写入 `open_questions`。
- 数据帧格式是否使用hardware interface报告中的真实第三章表号引用，而不是复制Byte/W布局、固定值、位域、编码、字段含义或完整帧结构。
- 请求与响应使用不同格式表时是否分别引用正确表号，且未把两张表内容拼接进TR。
- 保留的字段名称是否直接参与合法性校验、异常条件或差异分支；普通载荷字段和完整字段清单是否仍由第三章表格承载。
- 去除格式细节后，通信双方、方向、触发、正常结果和异常结果是否仍完整可测试。
- 表号缺失时是否未编造引用，并在`open_questions`记录接口、消息、缺失表号和已搜索关键词。
- 是否先按`interface_id + 通信方向和双方 + 正常应答 + 错误字段集合 + 错误应答`建立合并签名。
- 同一接口内是否仍存在仅消息名称、快帧/慢帧分类、ID、长度、布局、格式表号、周期或独立触发不同，但处理方式和结果高度一致的重复row。
- 快帧遥测和慢帧遥测处理一致时是否合并为一行，并分别保留消息名称和第三章格式表号。
- 合并项是否按首次出现顺序合并去重`source_refs`；多个显式来源TR号是否用`、`连接；纯派生项是否只保留一个`AUTO_TR_JK`。
- 只有方向/双方且非同一事务、正常应答、错误字段集合、错误应答或请求—响应语义不同的项是否保持分行。
