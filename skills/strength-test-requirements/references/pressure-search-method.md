# 强度搜索方法

强度测试中的饱和性探索应体现“从约束出发、逐步加压、粗到细定位”的方法。

## 基本过程

- 从设计约束、额定负载或已知正常点开始。
- 逐渐加大强度，例如缩短发送周期、增加数据量、增加并发功能、增加异常输入比例。
- 先用较粗步长定位正常与异常之间的区间。
- 再用更细步长在区间内查找更精确的异常点、故障点或丢帧点。
- 异常点和故障点要保持一段时间，确认状态稳定。
- 优先包含反复验证：故障后回到正常，再调回故障，确认边界可重复。

## 表述偏好

需求描述优先采用过程化表述：

- 以 XX 时间周期发指令，持续 XX 时间。
- 从 XX 间隔开始逐步缩小到 XX 间隔，记录正常、异常和故障状态。
- 在异常点或故障点保持 XX 时间，确认是否稳定复现。

如果原文只给出最终阈值，不要补造完整搜索过程；只保留原文给出的压力条件和判定结果。
