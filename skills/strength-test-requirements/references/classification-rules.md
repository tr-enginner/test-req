# 分类规则

强度测试只覆盖超出正常运行负载或接近极限条件下的稳定性、可靠性和抗压力能力验证。

## 长时间连续不间断综合功能测试

用于验证软件在长时间连续运行和综合输入持续施加下，各功能处理是否保持正确。

典型语义：

- 软件连续运行 25 小时等长时间场景。
- 以固定周期持续发送遥测、遥控、广播、时间码、数据包、读写指令等综合输入。
- 多种功能输入在同一长时间窗口内持续施加，并观察各功能处理情况。

## 提供数据能力的饱和性试验指标

用于验证从设计约束或正常负载开始逐步增大强度，寻找系统承受能力边界。

典型语义：

- 发送间隔从设计约束开始逐步缩小。
- 寻找正常稳定点、异常点、故障点、丢帧点或百分比阈值。
- 定义运行不正常和运行故障的判定状态。
- 记录从粗步长到细步长来回探寻的过程。

分类时按主要验证意图选择唯一类别。长时间连续运行和饱和性探索同时出现时，若重点是长时间综合施压，选 `长时间连续不间断综合功能测试`；若重点是逐步逼近承受边界，选 `提供数据能力的饱和性试验指标`。
