# 边界与端点

## 边界

边界用于阈值、比较条件或临界状态。需求描述保留原文的比较关系、开闭区间及跨越边界后的行为。不要在需求阶段自行展开成阈值减一、阈值、阈值加一等测试数据。

## 端点

端点用于有限输入或输出域的明确最小值、最大值，或明确状态序列的初始、终止状态。端点必须来自原文，不根据数据类型位宽推导。

## 常见证据

- `[a,b]`、`(a,b)`、`大于等于`、`小于`等开闭关系；
- 枚举集合、序号范围、数组下标和包计数；
- 地址合法区间、对齐要求及`起始地址+长度-1`约束；
- 温度、电压、电流、频率、角度、时间间隔设置值等范围；
- 输出限幅、饱和点、最小或最大输出；
- 状态进入、退出、启动、停止的阈值条件。

## 地址边界

程序注入、烧录、内存访问、缓冲区和数据搬运需要主动检查：起始/结束地址、合法地址区间、基址与偏移范围、地址对齐、禁止/保留/只读区、`起始地址+长度-1`、地址加法溢出或回绕、跨区及越过缓冲区边界。

地址row必须包含具体地址对象、原文明示的合法性依据和合法、越界或未对齐时的预期行为。程序注入起始地址、注入长度和二者组合形成的末地址约束，如果验证结果或异常处理不同，应分别生成row。

地址值保留原文进制、位宽、符号和单位。可以保留原文明示的`起始地址+长度-1`关系，但不得依据芯片位宽、存储容量或常识计算未给出的端点。离散合法地址、禁止地址和保留地址保持集合表达。仅有基址而没有范围、对齐或越界行为时不生成row；普通地址计算、文件写入或烧录步骤本身也不成立。

## 区间表达规范

新生成的`boundary_requirement_description`使用数学区间记法，逗号后统一保留一个空格：

- 原文`start~end`或`start～end`按包含两端写为`[start, end]`，例如`1~4`写为`[1, 4]`，`0x0001～0x0FFF`写为`[0x0001, 0x0FFF]`；
- 原文“大于start且小于end”写为`(start, end)`；
- 原文“大于等于start且小于end”写为`[start, end)`；其余半开关系同理；
- 单侧边界保留`>=`、`>`、`<=`、`<`等比较关系，不补造不存在的另一端；
- 枚举集合、状态集合和离散值保持集合或逐项表达，不改写为连续区间；
- 保留原文数值进制、精度、正负号和单位，十六进制值不得转为十进制；
- `100±10`等容差表达保持原样，不自行计算为端点；只有原文明示端点时才写区间。

格式统一不得改变原文开闭关系或推导新数值。
