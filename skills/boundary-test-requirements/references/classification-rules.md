# 分类规则

相关说明采用对象名称加受控后缀：

- `数据输入域边界测试`：输入阈值、比较条件或临界值两侧导致不同处理。
- `数据输入域端点测试`：有限输入域有明确最小值和最大值。
- `数据输出域边界测试`：输出阈值、饱和点或临界值附近有明确约束。
- `数据输出域端点测试`：有限输出域有明确最小值和最大值。
- `状态转换的边界点测试`：跨越明确阈值触发、阻止或改变状态转换。
- `状态转换的端点测试`：明确状态序列具有初始、终止或极端状态约束。

前四类必须在后缀前给出具体对象名称。地址属于输入域，使用现有后缀，例如`程序注入起始地址数据输入域端点测试`、`程序注入地址对齐数据输入域边界测试`、`程序注入末地址数据输入域边界测试`，不得新增“地址边界测试”后缀。状态转换类使用固定文本，不添加模糊前缀。

仅有数值但没有输入、输出或状态语义时不成立。仅有“极端”“临界”等定性词但没有原文边界依据时不成立。
