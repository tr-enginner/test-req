================================================================================
Matrix Embedded Agent — Code Review 能力验证操作步骤
================================================================================

目标：验证 Inspector agent 对测试用例中注入缺陷的检测能力（RS-01~RS-25）。

--------------------------------------------------------------------------------
一、准备
--------------------------------------------------------------------------------

1. 确认插件已构建：
   cd D:/claude_ws/matrix-embedded-agent && bun run build

2. 确认 ~/.config/opencode/opencode.jsonc 包含：
   { "plugin": ["file:///D:/claude_ws/matrix-embedded-agent/dist/index.js"] }

--------------------------------------------------------------------------------
二、执行
--------------------------------------------------------------------------------

1. 在 tests/review-cases/ 目录打开 opencode：
   cd D:/claude_ws/matrix-embedded-agent/tests/review-cases
   opencode

2. 执行完整流程（自动走 Phase 1 → Phase 2 → Phase 3）：
   /matrix-start

   Phase 3 中 Inspector 会对所有 .c 文件执行运行时安全缺陷分析。

--------------------------------------------------------------------------------
三、查看结果
--------------------------------------------------------------------------------

- 缺陷列表：.matrix/data/defects.json
- 审查报告：.matrix/reports/code-review.md

对照每个 tc-rs-XX-*.c 文件头部注释的"期望 Inspector 发现"验证结果。
