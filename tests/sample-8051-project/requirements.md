# 卫星电源控制器 软件需求规格说明书

## 1 概述

本文档定义了某微小卫星电源控制器（Power Control Unit, PCU）嵌入式软件的功能与性能需求。PCU 基于 8051 微控制器，负责太阳能电池阵列最大功率点跟踪（MPPT）、蓄电池充放电管理、母线电压调节、负载开关控制及遥测数据采集上报。

### 1.1 硬件平台

- MCU: 8051 兼容（12 MHz 晶振，片内 8 KB ROM / 256 Byte IDATA / 4 KB XDATA）
- ADC: 12-bit 逐次逼近型，8 通道
- DAC: 8-bit，用于 MPPT 参考电压输出
- UART: 与星务计算机通信（9600 bps）
- GPIO: 8 路负载开关驱动，4 路遥测离散量
- 看门狗: 硬件看门狗定时器，溢出周期 1.6 s

### 1.2 供电拓扑

太阳能电池阵列 → MPPT 变换器 → 28V 母线 ← → 蓄电池（14 节 NiCd，标称 16.8V）
母线 → 负载开关 × 8 → 各分系统

## 2 功能需求

### SRS-001 系统初始化

系统上电后应在 500 ms 内完成以下初始化：
- 配置定时器 0 为 10 ms 周期中断
- 配置 UART 为 9600 bps, 8N1
- 配置 ADC 采样序列（通道 0-7）
- 将所有负载开关设为断开状态
- 使能硬件看门狗
- 进入"安全模式"运行状态

优先级：**关键**

### SRS-002 太阳能电池阵列电压采集

系统应通过 ADC 通道 0 采集太阳能电池阵列电压（V_SA），采样周期 100 ms。
- ADC 输入范围：0 ~ 4095（对应 0 ~ 40.95 V，分辨率 10 mV/LSB）
- 有效范围：0 V ≤ V_SA ≤ 38.0 V
- 超出有效范围时标记为传感器故障

优先级：**关键**

### SRS-003 太阳能电池阵列电流采集

系统应通过 ADC 通道 1 采集太阳能电池阵列电流（I_SA），采样周期 100 ms。
- ADC 输入范围：0 ~ 4095（对应 0 ~ 4.095 A，分辨率 1 mA/LSB）
- 有效范围：0 A ≤ I_SA ≤ 3.5 A
- 超出有效范围时标记为传感器故障

优先级：**关键**

### SRS-004 MPPT 最大功率点跟踪

系统应实现扰动观察法（P&O）MPPT 算法，控制 DAC 输出参考电压以跟踪太阳能电池阵列最大功率点。
- MPPT 控制周期：1 s
- DAC 输出范围：0 ~ 255（对应 0 ~ 25.5 V 参考电压，分辨率 100 mV/LSB）
- 步长：功率增大时沿原方向调整 1 LSB，功率减小时反向调整 1 LSB
- 初始参考电压：70%×V_OC（开路电压），即 DAC = 178
- 安全约束：DAC 值不得低于 100 (10.0 V) 或超过 250 (25.0 V)

验收准则：在稳态日照条件下，实际工作点功率不低于理论最大功率的 95%

优先级：**关键**

### SRS-005 蓄电池电压监测

系统应通过 ADC 通道 2 采集蓄电池电压（V_BAT），采样周期 100 ms。
- ADC 输入范围：0 ~ 4095（对应 0 ~ 24.0 V，分辨率 5.86 mV/LSB）
- 充电上限阈值：19.6 V（过充保护）
- 放电下限阈值：14.0 V（过放保护）
- 正常工作范围：14.0 V ≤ V_BAT ≤ 19.6 V

优先级：**关键**

### SRS-006 蓄电池充放电管理

系统应根据蓄电池电压和母线状态控制充放电策略：

| 条件 | 动作 |
|------|------|
| V_BAT ≥ 19.6V | 停止充电（断开充电通路） |
| V_BAT < 19.0V 且有太阳能功率 | 恢复充电 |
| V_BAT ≤ 14.0V | 触发欠压保护，切断非关键负载 |
| V_BAT > 14.5V 且欠压保护激活 | 解除欠压保护，恢复负载 |

充电模式切换应有 0.6V 迟滞以避免振荡。

优先级：**关键**

### SRS-007 母线电压监测与调节

系统应通过 ADC 通道 3 采集母线电压（V_BUS），采样周期 100 ms。
- 标称值：28.0 V
- 正常范围：26.0 V ≤ V_BUS ≤ 30.0 V
- 过压保护阈值：32.0 V（触发太阳能阵列短路保护）
- 欠压告警阈值：25.0 V

优先级：**高**

### SRS-008 负载开关控制

系统应提供 8 路独立负载开关控制（LOAD_SW[0..7]），支持：
- 星务计算机遥控指令开关
- 本地自主保护切断（欠压保护时切断非关键负载）
- 负载优先级定义：
  - 关键负载（不可切断）：LOAD_SW[0]（星务计算机）, LOAD_SW[1]（测控应答机）
  - 非关键负载（可自主切断）：LOAD_SW[2..7]

每路开关动作后应回读状态确认，若状态不一致则上报遥测异常。

优先级：**高**

### SRS-009 遥测数据采集与上报

系统应按以下周期采集遥测数据并通过 UART 上报：

| 遥测参数 | 周期 | 格式 |
|---------|------|------|
| V_SA, I_SA, P_SA | 1 s | 16-bit 无符号 |
| V_BAT | 1 s | 16-bit 无符号 |
| V_BUS | 1 s | 16-bit 无符号 |
| 蓄电池充电状态 | 1 s | 枚举 (0=停充, 1=充电, 2=欠压) |
| 负载开关状态 | 1 s | 8-bit 位图 |
| MPPT DAC 值 | 1 s | 8-bit |
| 故障字 | 1 s | 16-bit 位图 |

遥测帧格式：帧头(0xEB90) + 帧长(1B) + 数据(NB) + 校验和(1B)

优先级：**高**

### SRS-010 故障检测与处理

系统应检测以下故障并置位对应故障字位：

| 位 | 故障 | 处理 |
|----|------|------|
| 0 | 太阳能阵列过压 (V_SA > 38.0V) | MPPT DAC 置最小值 |
| 1 | 太阳能阵列传感器故障 | MPPT 冻结当前 DAC 值 |
| 2 | 蓄电池过充 (V_BAT ≥ 19.6V) | 断开充电通路 |
| 3 | 蓄电池过放 (V_BAT ≤ 14.0V) | 切断非关键负载 |
| 4 | 母线过压 (V_BUS > 32.0V) | 太阳能阵列短路保护 |
| 5 | 母线欠压 (V_BUS < 25.0V) | 上报告警 |
| 6 | 负载开关状态不一致 | 上报遥测异常 |
| 7 | 看门狗预警 | 强制喂狗 |

故障字应在遥测帧中上报。致命故障（位 0、2、3、4）应立即处理，不等待下一控制周期。

优先级：**关键**

## 3 性能需求

### NFR-001 控制周期

10 ms 定时器中断内的全部处理（ADC 采集 + 控制计算 + 输出更新）应在 8 ms 内完成。

优先级：**关键**

### NFR-002 内存约束

- ROM 使用不超过 7 KB（预留 1 KB 用于 Bootloader）
- IDATA 使用不超过 200 Byte
- XDATA 使用不超过 3.5 KB

优先级：**高**

---

## 4 接口需求

### IR-001 UART 通信接口

与星务计算机的 UART 通信接口规格：
- 波特率：9600 bps
- 格式：8 数据位, 无校验, 1 停止位
- 遥控指令帧：帧头(0xEB90) + 指令码(1B) + 参数(2B) + 校验和(1B)
- 指令码定义：
  - 0x01: 负载开关控制（参数：通道号 + 开关状态）
  - 0x02: MPPT 模式切换（参数：0=自动, 1=手动固定电压）
  - 0x03: 遥测请求
  - 0xFF: 复位

优先级：**高**
