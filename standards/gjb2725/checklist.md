# GJB 2725 Test Documentation Checklist

GJB 2725 (Military Software Test Documentation) requirements for test artifacts.

## Test Requirement Specification
- [ ] Each test requirement traces to at least one software requirement
- [ ] Test type clearly specified (functional/interface/performance/robustness)
- [ ] Verification method defined (test/analysis/inspection/demonstration)
- [ ] Pass/fail criteria explicitly stated
- [ ] Testability assessment completed

## Test Case Specification
- [ ] Each test case traces to at least one test requirement
- [ ] Test steps numbered and detailed
- [ ] Input data clearly specified with values and formats
- [ ] Expected results precisely defined
- [ ] Judgment criteria unambiguous
- [ ] Preconditions and postconditions documented
- [ ] Test environment requirements stated

## Test Execution Record
- [ ] Each step has actual result recorded
- [ ] Pass/fail/blocked verdict for each step
- [ ] Evidence (logs/screenshots) captured for failures
- [ ] Defect IDs linked to failed steps
- [ ] Execution date and executor recorded
- [ ] Environment configuration documented

## Test Summary Report
- [ ] Overall test conclusion stated
- [ ] Requirement coverage metrics calculated
- [ ] Pass rate metrics included
- [ ] Defect summary by severity
- [ ] Open defect list with impact assessment
- [ ] Risk items identified with mitigations
- [ ] Recommendations for next steps
